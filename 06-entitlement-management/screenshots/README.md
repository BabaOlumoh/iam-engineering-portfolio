## Screenshot Redaction Guidance

Before uploading screenshots to GitHub, redact:

- Tenant ID
- Object IDs
- User personal data
- Real email addresses where required
- Authentication methods
- IP addresses
- Any confidential business data

Use lab users and lab tenant data where possible.
